# Заметки

Мобильное приложение для рукописных и текстовых заметок. Лист можно рисовать стилусом или пальцем, ставить текст, стикеры и фото, раскладывать это по слоям и группам.

Сделано на Expo SDK 58 и React Native. Линии холста рисует Skia.

## Возможности

- Перо с нажимом, маркер, ластик и фигуры
- Текст, стикеры и фото на листе, обрезка и маски
- Слои, группы листов и закрепление
- Экспорт листа в PNG и PDF
- Поиск по названию и тексту

## Требования

- Node.js 22 или новее
- npm 11
- Телефон с [Expo Go](https://expo.dev/go) для SDK 58

## Запуск

```bash
npm install
npx expo start
```

Если телефон не в той же сети, что и компьютер:

```bash
npx expo start --tunnel
```

Проверка типов:

```bash
npx tsc --noEmit
```

## Структура

```text
App.tsx                         точка входа экранов
index.ts                        регистрация приложения
app.json                        имя, версия, идентификаторы iOS и Android
eas.json                        профили облачной сборки
assets/                         иконки
src/
  components/                   список листов и редактор
  components/canvas/            холст, инструменты, слои
  hooks/useNotes.ts             состояние и сохранение
  storage.ts                    заметки на устройстве
  strokeUtils.ts                штрихи, ластик, фигуры
  skiaStrokes.tsx               отрисовка линий
  media.ts                      фото на листе
  exportNote.ts                 PNG и PDF
  types.ts                      общие типы
```

Папки `ios/` и `android/` в репозиторий не входят: Expo собирает их при сборке.

## Версии

Номер версии один: поле `version` в `package.json` и `expo.version` в `app.json`. Формат [SemVer](https://semver.org/lang/ru/): `МАЖОР.МИНОР.ПАТЧ`.

| Что меняется | Какую цифру поднять |
| --- | --- |
| Ломающее изменение хранения или жестов | мажор: `2.0.0` |
| Новая возможность | минор: `1.1.0` |
| Исправление | патч: `1.0.1` |

Рядом с версией для магазинов стоят отдельные номера сборки. Их увеличивают на единицу при каждой выкладке, даже если версия для людей та же.

- Android: `android.versionCode` в `app.json`
- iOS: `ios.buildNumber` в `app.json`

Сейчас: версия **1.0.0**, сборка **1**. История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Сборка

Облачная сборка через EAS. Версия берётся из `app.json`, не из счётчика на сервере.

```bash
npx eas-cli@latest build -p android --profile preview
npx eas-cli@latest build --profile production
```
